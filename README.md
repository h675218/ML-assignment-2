# Sports Image Classification Platform

A full-stack machine learning application that classifies images as either **hockey** or **tennis** using a Convolutional Neural Network (CNN). The project combines deep learning, API development, and web technologies by integrating a TensorFlow/Keras model with a FastAPI prediction service and a Java Spring Boot web interface.

## Overview

The purpose of this project was to gain hands-on experience with machine learning and computer vision beyond the university curriculum while exploring how trained models can be deployed as part of a complete software system.

The application allows users to upload an image through a web interface and receive a real-time prediction generated by a trained CNN model.

The project covers the entire machine learning workflow:

- Dataset preparation and organization
- Image preprocessing
- Data augmentation
- CNN development and training
- Model evaluation
- API development using FastAPI
- Frontend integration using Spring Boot
- Deployment of a trained machine learning model

---

## Features

- Binary image classification (Hockey vs Tennis)
- Trained on more than 1300 labelled images
- Data augmentation to improve model generalization
- Interactive web interface for image uploads
- Real-time predictions through a FastAPI service

## System Architecture

```text
User Uploads Image
        │
        ▼
Spring Boot Web Interface
        │
        ▼
FastAPI Prediction Service
        │
        ▼
TensorFlow/Keras CNN Model
        │
        ▼
Classification Result
        │
        ▼
Displayed to User
```

The trained CNN model is loaded by the FastAPI service, which handles inference requests from the Spring Boot web application.

---

## Model Development

The model was trained using a dataset containing more than 1300 hockey and tennis images.

The training pipeline included:

- Image resizing and normalization
- Data augmentation using ImageDataGenerator
- Convolutional feature extraction
- Dense classification layers
- Evaluation on a dedicated test dataset

The final model achieved a test accuracy exceeding **95%**.

## Installation

### Clone the Repository

### Create a Virtual Environment

```bash
python -m venv .venv
```

#### macOS / Linux

```bash
source .venv/bin/activate
```

#### Windows

```bash
.venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Running the Application

### Start the FastAPI Prediction Service

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### Start the Spring Boot Application

```bash
cd webapp/cnnweb

mvn spring-boot:run
```

The web application will be available at:

```text
http://localhost:8080
```
